# PTT 消費者觀點分析：貓食品 × 電視

從 PTT 收集 **2021/1/1 至今** 討論「貓食品」與「電視」的文章與留言，統計消費者最常討論的面向（例如適口性、價格、保固）與品牌，產出可直接放進簡報的表格與圖表。

## 專案結構

```
ptt-consumer-insights/
├── config.py         設定清單：搜尋詞、看板、時間範圍、面向詞庫、品牌（唯一需要調整的檔案）
├── 1_scrape.py       第 1 步：爬 PTT 文章與留言
├── 2_analyze.py      第 2 步：篩選、統計面向與品牌、產出表格與圖
├── check_word.py     輔助工具：抽查某個詞在文章中的實際用法
├── requirements.txt  需要安裝的套件
├── data/             爬下來的資料（不上傳）
└── output/           分析結果（不上傳）
```

## 安裝

需要 Python 3.10 以上。

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows：.venv\Scripts\activate
pip install -r requirements.txt
```

## 使用方式

### 第 1 步：爬資料

```bash
python 1_scrape.py
```

- 依 `config.py` 的設定，到每個看板搜尋每個搜尋詞。
- 從最新文章往前翻，翻到 `START_DATE` 之前就停，所以範圍由**日期**決定，不是頁數。
- 標題含 `TITLE_EXCLUDE`（交易、售出、送養等）的文章直接跳過。
- 同一篇文章被多個品項搜到時，內容只抓一次，`items` 欄位會記錄所有品項（例如 `飼料|罐頭`）。
- 每搜完一組就存檔；中途中斷後再執行，會跳過已抓過的文章。
- 建議先把 `config.py` 的 `TEST_MODE` 設為 `True` 測試，幾分鐘內就能確認程式能正常運作。

產出：
- `data/ptt_articles.csv`：一篇文章一列（子類別、品項、看板、日期、標題、內文、網址等）
- `data/ptt_comments.csv`：一則留言一列，以 `url` 對應文章

### 第 2 步：分析

```bash
python 2_analyze.py
```

1. **篩選**：排除標題含不相關字詞的文章（例如「電視劇」）以及 `[情報]` 文，排除原因全部記錄下來。
2. **面向**：把每篇文章的「標題＋內文＋留言」合在一起；只要出現某面向詞庫中的任一個詞，就算有提到這個面向。
3. **品牌**：用同樣方式計算每個品牌的提及比例。
4. **高頻詞**：用 jieba 斷詞，找出最常出現的詞，作為補充詞庫的參考。

產出（`output/`）：

| 檔案 | 內容 |
|---|---|
| `01_篩選紀錄.csv` | 每篇文章保留或排除，以及排除原因 |
| `02_面向統計.csv` | 每個品項 × 每個面向的提及篇數與比例 |
| `03_Top3_<子類別>.png`、`03_Top3表格.csv` | 每個品項前三名面向，以及輔助面向 |
| `04_面向長條圖_<子類別>.png` | 子類別整體的各面向提及比例 |
| `05_品牌統計.csv` | 各品牌提及篇數與比例 |
| `06_高頻詞.csv` | 各子類別最常出現的 100 個詞 |

修改詞庫或排除規則後，只需重跑 `2_analyze.py`，不用重新爬資料。

### 輔助工具：抽查詞彙

```bash
python check_word.py 不吃 貓食品
```

列出這個詞出現在多少篇文章、在標題／內文／留言各幾次，並隨機顯示 10 段前後文，用來判斷這個詞是否會造成誤判。

## 如何調整

所有設定都在 `config.py`：

| 想要… | 修改的段落 |
|---|---|
| 新增品項或搜尋詞 | 1. `CATEGORIES` |
| 新增或移除看板 | 2. `BOARDS` |
| 改變時間範圍 | 3. `START_DATE` |
| 排除更多不相關的文章 | 6. `ANALYSIS_EXCLUDE_TITLE`、`MANUAL_EXCLUDE` |
| 是否排除 `[情報]` 文 | 6. `EXCLUDE_INFO_POSTS` |
| 調整面向詞庫 | 7. `ASPECTS`、8. `AUX_ASPECTS` |
| 調整品牌 | 9. `BRANDS` |

改了 1～4 段需要重新爬資料；改了 6～10 段只需重跑分析。

## 方法說明與限制

- **PTT 搜尋只比對標題**：內文有討論、但標題沒有搜尋詞的文章不會被收錄。
- **「提及」不等於「正面」或「負面」**：「價格」比例高，代表常被討論，不代表大家覺得便宜或貴。
- **詞庫比對有誤判的可能**：建議用 `check_word.py` 抽查比例異常的詞。本專案已依抽查結果做了以下調整：
  - 電視「尺寸與空間」移除「吋」：幾乎每篇電視文都會寫「65吋」這類規格，無法代表「在意尺寸」。
  - 排除 `[情報]` 文：特價資訊文會灌高「價格」與「購買通路」的比例。
- **詞庫不放搜尋詞本身**：例如「主食罐」不放進任何面向，否則被搜進來的文章一定會被算到，比例失去意義。
- **輔助面向不列入 Top 3 排名**：貓食品的「專業建議與資訊來源」、電視的「購買通路」是觀察用的面向，不直接代表商品需求。
- **一篇文章可屬於多個品項**：各品項的篇數加總可能大於子類別總篇數。
- **樣本數**：篇數少於 30 的品項，比例僅供參考。

## 資料來源與使用

資料來自 [PTT](https://www.ptt.cc) 公開看板。爬蟲每次請求間隔 1.5～3 秒，以避免對伺服器造成負擔。爬下來的原始資料含有使用者帳號，因此不放在此 repository 中。
